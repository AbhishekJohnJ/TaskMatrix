           STEP-BY-STEP DEPLOYMENT GUIDE
═══════════════════════════════════════════════════════════

OPTION 1: VERCEL WEBSITE (EASIEST) 👈 RECOMMENDED
──────────────────────────────────────────────────────────

1. GO TO: https://vercel.com
   → Sign in with GitHub

2. CLICK: "Add New" → "Project"

3. IMPORT: Select your "TaskMatrix" repository

4. CONFIGURE:
   Root Directory: client
   Framework: Vite (auto-detected)
   Build Command: npm run build
   Output Directory: dist

5. ADD ENVIRONMENT VARIABLES:
   
   VITE_API_URL = https://placeholder.com/api
   VITE_SOCKET_URL = https://placeholder.com
   VITE_APP_NAME = TaskMatrix
   VITE_APP_VERSION = 1.0.0

6. CLICK: "Deploy" button

7. WAIT 2-3 minutes...

8. DONE! 🎉 Visit your URL: https://your-project.vercel.app

═══════════════════════════════════════════════════════════

OPTION 2: USING GIT (AUTOMATIC DEPLOYMENT)
──────────────────────────────────────────────────────────

1. PUSH YOUR CHANGES:
   
   git add .
   git commit -m "Deploy login page"
   git push origin main

2. Then follow Option 1 above to connect Vercel to your repo

3. Future pushes will auto-deploy! 🚀
